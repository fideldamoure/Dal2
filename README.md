# مطابقة القرارات الإدارية (baladiya_check)

تطبيق Flutter لمسح القرارات الإدارية الورقية (قرارات البلديات) وتقييم مطابقتها لتشريع الوظيفة العمومية الجزائرية.

> النتائج ملاحظات أولية للمراجعة وليست رأيًا قانونيًا نهائيًا.

## كيف يعمل

1. تصوير القرار أو اختياره من المعرض.
2. OCR عربي عبر Tesseract (دون إنترنت).
3. استخراج الرقم والتاريخ والجهة والتأشيرات والمواد.
4. فحص القواعد المعرَّفة في `assets/rules/rules.json`.
5. عرض المرجع القانوني لكل ملاحظة من قاعدة النصوص.

## مصدر النصوص القانونية (اختياري ومتبدّل)

| الخيار | الوصف |
|---|---|
| محلي | SQLite على الهاتف، يُملأ من `assets/legal/seed.json` أو بالاستيراد لاحقًا (`LocalLegalSource.importTexts`). |
| سحابي | جدول `legal_texts` على خدمتك (مثل Supabase). يُدخل الرابط والمفتاح من الإعدادات داخل التطبيق، ولا يُحفظ أي سر في المستودع. |

مخطط الجدول السحابي:

```sql
create table legal_texts (
  id text primary key,
  title text not null,
  reference text,
  article_no text,
  body text
);
```

## التشغيل

```bash
flutter create --platforms=android .   # مرة واحدة لتوليد مجلد android
flutter pub get
# ضع ara.traineddata داخل assets/tessdata/
flutter run
```

على GitHub: كل دفع إلى `main` يشغّل `.github/workflows/build.yml` الذي يحلل الشيفرة ويشغّل الاختبار ويبني ملف APK.
